Pragma

v0.1.0 · latest release

An agentic AI coding harness — a Rust agentic loop with 13 core tools, multi-provider streaming, SQLite persistence, and browser-style tabs. Installers are built per release and hosted on GitHub Releases.

Linux
Debian/Ubuntu (deb), any distro (AppImage), or Fedora/RHEL (rpm).
AppImage — run without installing .deb — Debian / Ubuntu / Mint .rpm — Fedora / RHEL / openSUSE
macOS
Apple Silicon (M-series) and Intel. Unsigned — see the note below.
.dmg — Apple Silicon .app.tar.gz — Apple Silicon (no installer) Intel Mac — in the follow-up release (CI runner was backlogged)
Windows
Windows 10/11. Pick the installer or the portable executable.
.msi installer .exe (NSIS) installer
First release notes: builds are unsigned — macOS will warn “unidentified developer” (right-click → Open, or xattr -dr com.apple.quarantine on the app), and Windows SmartScreen will prompt. Code-signing is on the roadmap.

After installing, head to Settings → Marketplace in the app to install plugins — they ship as npm packages (pragma-plugin-*) with one-click installs. npm i -g pragma-app is also an install path.
