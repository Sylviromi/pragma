After installing

Pragma checks for new releases in the background and offers a one-click Install & restart with the changelog shown first — you won't need this page again.

Plugins install from inside the app: Settings → Marketplace (npm packages named pragma-plugin-*).

Arch Linux: a source-built AUR package is planned — use the .deb or .AppImage for now.

Unsigned builds

macOS and Windows binaries aren't code-signed, so the OS shows a warning. macOS: right-click → Open, or xattr -dr com.apple.quarantine on the app. Windows: More info → Run anyway.
